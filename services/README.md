# Servicios

Cada subdirectorio representa un microservicio desplegable y dueño exclusivo de
su modelo, persistencia y migraciones.

Módulos previstos según el contrato funcional:

- `identity-service`
- `company-service`
- `catalog-service`
- `sales-service`
- `expense-service`
- `finance-service`
- `api-gateway`

Solo `company-service` forma parte de `S2-294`. Los demás módulos se crean en sus
tickets correspondientes.
